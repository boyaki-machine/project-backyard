## 1. 置く

同梱の `{{.ZipEntryName}}` を、**作業フォルダの直下**へ移し、
**`{{.ConfigPath}}` へ改名してください**。

**改名が要るようにしてあるのは、展開した瞬間に既にある設定を消さないためです。**
`{{.ConfigPath}}` は履歴管理の対象外なので、消えても git からは戻せません。

**既に `{{.ConfigPath}}` がある場合は、置き換えないでください。**
中の `mcpServers` に `pb` の項だけを足します（他の MCP サーバの設定が消えます）。

## 2. 履歴管理から外す

`.gitignore` に `{{.ConfigPath}}` が入っていることを確かめてください。
プロジェクト設定の「エージェント連携セットアップ」が生成する `.gitignore` には
既に入っています。**入っていないまま commit すると、あなたの環境が履歴に残ります。**

## 承認待ちを作業時間から除く（フック）

同梱の `.claude/settings.local.pb-block.json` を作業フォルダの `.claude/` へ移し、
**`settings.local.json` へ改名してください**（既にある場合は、中の `hooks` に項だけを足します）。

{{.ClientDisplayName}} が承認を求めている間、PB の作業記録を止めておくフックです。承認を求める直前に止め、
次にツールが動いた後か、あなたが何か入力した後に再開します。**入れなくても PB には繋がります**が、
承認を待った時間（席を外していた時間を含む）が作業時間に入ります。
`settings.local.json` も各自の環境です。`.gitignore` に入っていなければ足してください。

**HTTP のフックに対応した {{.ClientDisplayName}} が要ります。** 古い版は、このフックを黙って飛ばします
（2.1.50 では走らず、2.1.173 では走ることを確かめました）。`/hooks` に載っていても、承認待ちが作業時間に入るなら更新してください。

## 繋がらないとき

| 症状 | 見るところ |
|---|---|
| ツールが1つも見えない | クライアントは接続時に一覧を覚えます。**開き直してください** |
| `401` | 環境変数が空か、トークンが失効しています。**新しいシェルで開き直したか**も見てください |
| `404` | URL のプロジェクトと、トークンのプロジェクトが食い違っています |
| `403` | トークンのスコープか、所有者であるあなたの権限が足りません |
