**手順**

1. お使いのクライアントが OS の信頼ストアを読むなら、何もしなくて構いません。
2. Node で動くクライアント（Gemini CLI など）は既定では読まないので、起動する前のシェルで次を設定します。

   ```
   export NODE_USE_SYSTEM_CA=1
   ```

3. 新しいシェルでクライアントを起動し、繋がることを確かめます。

**うまくいかないとき**

- 古い Node では 2 が効かないことがあります。代わりに、CA の証明書を渡します。

  ```
  export NODE_EXTRA_CA_CERTS="$(mkcert -CAROOT)/rootCA.pem"
  ```
