# {{.ProjectName}} — {{.ClientDisplayName}} の接続設定

このファイルは Project Backyard が「{{.DisplayName}}」のために生成しました。
**この zip の中身は、あなたの端末にだけ置くものです。リポジトリにコミットしません。**

## 先に読んでください

**設定 > コネクタ（カスタムコネクタ）からは繋がりません。** あちらの接続は、あなたの端末から
ではなく **Anthropic のクラウドから**相手のサーバへ届きます。PB は手元で動いているので
クラウドからは到達できず、**https も必要になります。** 残る経路が、この手引きが説明する
**設定ファイル**です。

**{{.ClientDisplayName}} の設定ファイルは stdio のサーバしか書けません。** PB は HTTP なので、
間に橋（`mcp-remote`）を挟みます。**橋が PB と往復できることは実測しました**（`initialize` と
`tools/list` が通っています）。**{{.ClientDisplayName}} 自身がこの設定を読んで起動するところは、
まだ確かめられていません。**

## 1. 設定ファイルを開く

{{.ClientDisplayName}} の **Settings > Developer > Edit Config** から `{{.ConfigPath}}` を開きます。

**丸ごと置き換えないでください。** 中の `mcpServers` に `pb` の項だけを足します
（他の MCP サーバの設定が消えます）。同梱の `{{.ZipEntryName}}` が、その足す内容です。

## 2. 貼り替える欄が2つあります

**PB はあなたの端末に node がどこにあるかを知りません。** 生成した設定には「ここに貼る」と
書いた欄が2つあるので、埋めてください。

```
which npx             → command に貼る
dirname $(which node) → env の PATH の先頭に貼る
```

**`"command": "npx"` とだけ書くと起動しません。** {{.ClientDisplayName}} は GUI アプリで、
**シェルの `PATH` を継承しない**ためです。**絶対パスにしても足りません**——`npx` 自身が
`node` を `PATH` から探すので、`env` の `PATH` にも同じディレクトリが要ります。
**どちらも実測で踏みました。**

**nvm を使っている場合、このパスに node のバージョンが入ります。** node を上げると
設定が壊れるので、そのときは2か所とも直してください。

## 3. トークンを設定ファイルに書く

`env` の `{{.TokenEnvName}}` に、**発行時に一度だけ表示された値**を入れます。
控えていない場合は、PB の `自分の設定 → エージェント` で**再発行**してください
（再発行すると、それまでのトークンは失効します）。

**{{.ClientDisplayName}} では `export` 行が効きません。** シェルの環境変数は GUI アプリに
届かないためで、**トークンの平文が設定ファイルに残ることは避けられません。**
このファイルは共有しないでください。

## 4. 完全に終了してから起動し直す

**窓を閉じるだけでは足りません。** {{.ClientDisplayName}} を完全に終了してから起動します。

起動したら「PB に参画して」と伝えます。うまくいけば、プロジェクトの概要・憲章・自分の担当
チケットが返ります。**PB の画面（自分の設定 → エージェント）に「接続済み」のチェックが付きます。**

## 繋がらないとき

**{{.ClientDisplayName}} は原因を「サーバが起動しない」としか出しません。** 症状から切り分けます。

| 見えること | 見るところ |
|---|---|
| サーバが出てこない | `command` と `env` の `PATH` を貼り替えたか。**両方要ります** |
| 起動して即座に落ちる | トークンが違うか失効しています。**`401` を受けると橋は OAuth を試みて落ちる**ので、認証の失敗に見えません |
| ツールが1つも見えない | 完全に終了してから起動し直したか |
| 繋がるが `404` | URL のプロジェクトと、トークンのプロジェクトが食い違っています |
| 繋がるが `403` | トークンのスコープか、所有者であるあなたの権限が足りません |
