# {{.ProjectName}} — {{.ClientDisplayName}} の接続設定

このファイルは Project Backyard が「{{.DisplayName}}」のために生成しました。
**この zip の中身は、あなたの端末にだけ置くものです。リポジトリにコミットしません。**

## 1. 置く

同梱の `{{.ZipEntryName}}` を、**作業フォルダの直下**へ移し、
**`{{.ConfigPath}}` へ改名してください**（`.vscode` フォルダごと入っています）。

**改名が要るようにしてあるのは、展開した瞬間に既にある設定を消さないためです。**
`{{.ConfigPath}}` は履歴管理の対象外なので、消えても git からは戻せません。

**既に `{{.ConfigPath}}` がある場合は、置き換えないでください。**
中の `servers` に `pb` の項を、`inputs` に `pb-token` の項を足します。

## 2. 履歴管理から外す

`.gitignore` に `{{.ConfigPath}}` が入っていることを確かめてください。
プロジェクト設定の「エージェント連携セットアップ」が生成する `.gitignore` には
既に入っています。**入っていないまま commit すると、あなたの環境が履歴に残ります。**

## 3. トークンは環境変数に置きません

**{{.ClientDisplayName}} だけは、この手順がありません。**
VS Code が初回の接続時にトークンの入力を求め、以降は安全に保存します
（設定ファイルの `${input:pb-token}` がそれです）。**ファイルに実体は残りません。**

入力を求められたら、**発行時に一度だけ表示された値**を貼ります。
控えていない場合は、PB の `自分の設定 → エージェント` で**再発行**してください
（再発行すると、それまでのトークンは失効します）。

## 4. 起動して参画する

VS Code を開き直し、**Copilot をエージェントモードにして** {{.OnboardRef}}を実行します。
うまくいけば、プロジェクトの概要・憲章・自分の担当チケットが返ります。

**PB の画面（自分の設定 → エージェント）に「接続済み」のチェックが付きます。**

## 繋がらないとき

| 症状 | 見るところ |
|---|---|
| ツールが1つも見えない | **エージェントモードになっているか**を見てください（通常のチャットでは MCP ツールが出ません）。それでも出なければ VS Code を開き直します |
| `401` | 入力したトークンが違うか、失効しています |
| `404` | URL のプロジェクトと、トークンのプロジェクトが食い違っています |
| `403` | トークンのスコープか、所有者であるあなたの権限が足りません |
