## 1. 置く

同梱の `{{.ZipEntryName}}` を、**作業フォルダの直下**へ移し、
**`{{.ConfigPath}}` へ改名してください**。ZIP内では Finder などで隠れないよう
`_codex` フォルダにしています。まず `_codex` を `.codex` に変え、その中の
`config.pb-block.toml` を `config.toml` に変えます。

**改名が要るようにしてあるのは、展開した瞬間に既にある設定を消さないためです。**
`{{.ConfigPath}}` は履歴管理の対象外なので、消えても git からは戻せません。

**既に `{{.ConfigPath}}` がある場合は、置き換えないでください。**
`[mcp_servers.pb]` の節と、その下の `[mcp_servers.pb.tools.*]` を足します。

**{{.ClientDisplayName}} がプロジェクト直下の設定を読むのは、信頼済みのプロジェクトに限ります。**
読まれていないときは、そのフォルダを信頼するか、同じ内容を `~/.codex/config.toml` へ置きます。

## 2. 履歴管理から外す

`.gitignore` に `{{.ConfigPath}}` が入っていることを確かめてください。
プロジェクト設定の「エージェント連携セットアップ」が生成する `.gitignore` には
既に入っています。**入っていないまま commit すると、あなたの環境が履歴に残ります。**

## TLS 証明書

{{if eq .Transport "bridge"}}
このZIPは **ローカル stdio ブリッジ** 用です。同梱の `pb-mcp-bridge` を作業フォルダ外の
安全なローカルディレクトリへ置き、実行可能にして PATH へ加えます。ブリッジは待受ポートを開かず、
TLS検証も無効化しません。自己署名・社内 CA の PEM を安全な場所に保存して、次を設定します。

```
export PB_MCP_CA_FILE='/安全な場所/your-pb-ca.pem'
```

削除時は `[mcp_servers.pb]` と配下の tool 節、`pb-mcp-bridge`、CA PEM、
`PB_MCP_CA_FILE` を削除してから {{.ClientDisplayName}} を再起動します。
{{else}}
このZIPは **HTTPS 直接接続** 用です。公的 CA の証明書は通常 OS の信頼ストアで既に信頼されるため、
追加登録は不要です。自己署名・社内 CA のときだけ、発行元 CA を OS の信頼ストアへ登録します。

macOS はキーチェーンアクセスで対象 CA を「常に信頼」、Windows は証明書マネージャーの
「信頼されたルート証明機関」、Linux はディストリビューションの CA ストアを使います。登録前に
CA 指紋を PB 管理者へ照合し、不要になったら**同じ CA だけ**を削除します。TLS検証を無効化しないでください。
{{end}}

## 繋がらないとき

| 症状 | 見るところ |
|---|---|
| ツールが1つも見えない | 設定が読まれていません。**そのフォルダが信頼済みか**を見てください。開き直しも要ります |
| `401` | 環境変数が空か、トークンが失効しています。**新しいシェルで開き直したか**も見てください |
| `404` | URL のプロジェクトと、トークンのプロジェクトが食い違っています |
| `403` | トークンのスコープか、所有者であるあなたの権限が足りません |
