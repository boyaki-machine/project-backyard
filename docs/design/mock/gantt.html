第6版で変えたこと

いただいた点どう描いたか
暦の地域は見る人のタイムゾーンで見る人のタイムゾーンが Asia/Tokyo か Asia/Seoul なら「土＝青、日祝＝赤」、それ以外なら「土日＝灰、祝＝赤」にします。何日が休日かはプロジェクトの暦で決まり、見る人で変わるのは塗り方の慣習だけです
週末の曜日が違う地域別のチケット（pb-227）として起票しました
blocks を太く線を 1px から 1.8px に（強調時 2.3px）、止め（⊣）を 3px・高さ 12px にしました
ダークの詳細ペインが明るすぎる中間の濃さのチャコールグレーにしました（明度 0.275・不透明度 90%。画面の地 0.17 より一段明るく浮く）。本文は明度 0.93、見出しと補助の文字は 0.68、区切り線は 0.37 です

第5版で変えたこと

いただいた点どう描いたか
時計は採らない外しました
詳細ペインを無彩色に基調色を混ぜるのをやめ、ほぼ無彩色（彩度 0.004。8.1 の「純灰を使わない」に合わせてわずかに基調色を含む）の半透明にしました。ライトは明度 0.975・不透明度 84%。ダークでも明るいグレー（明度 0.84・不透明度 88%）の面に濃い文字を載せます。ペインの中だけ文字と線の色を明るい面用に差し替え、本文は 12:1 前後、補助の文字は 6:1 前後のコントラストにしています
blocks を別のものと分かるように線を一点鎖線にし、受け側の端を矢印ではなく止め（⊣）にしました。「先行が終わるまで止める」を形で示します。経路は FS と同じ（終わり→始まり）です
地域で土日祝の色を変える「暦の地域」で切り替えて見比べられます。日本・韓国は 土＝青み、日祝＝赤み。その他は 土日＝淡い灰、祝日＝赤み＋斜線です。祝日を赤で刷る慣習（red letter day）は欧州・北欧・香港・インドネシア・中南米の一部にもありますが、土曜を青くするのは日本と韓国の慣習だからです

第4版で変えたこと（手帳の配色をもとに。時計は第5版で外した）

いただいた点どう描いたか
スプリントのネオン進行中はオレンジ、それ以外はシアンにしました。どちらも発光させ、計画中は破線、完了は薄くしています。進行中の名前もオレンジで出します
祝日の斜線・土日の塗りを控えめに塗りの濃さを約6割に落としました。斜線は間隔を 6px から 8px へ広げ、濃さをライトで約半分、ダークで約4割に落としています
行と日の区切り線を控えめに日の縦線を 0.8 から 0.45（ダーク 0.55）へ、行の横線を 0.45 から 0.3（ダーク 0.7 から 0.4）へ下げました。大目盛りの十字も少し薄くしています
ネオンの重なり順描く順を、土日祝 → 格子 → スプリントの枠 → 「今」の線 → 依存線 → バーに変えました。枠が日の線で分断されなくなります
ダークでバーを輝かせるダークでだけ、完了以外のバーとマイルストーンに弱い発光（ぼかし半径 2.5px）を付け、枠線を明るい段へ寄せ、塗りを 36% から 42% に上げました。文字と依存線には付けていません（読みやすさを優先）
30分・15分の極薄の点線1日の幅が 1200px 以上（分の段階の手前）で 30分ごと、3600px 以上で 15分ごとに点線を引きます。拡大の上限を 4000px から 5760px（1分 = 4px）へ上げ、15分の点線が見える余地を作りました
ヘッダの時計（遊び）ページヘッダの空きに置きました。プレートに年と日付、刻みのあるベゼルのアナログ時計です。見る人のタイムゾーンの時刻を出し、秒針はオレンジで1秒ごとに進みます（動きを減らす設定のときは秒針を出さない）。ダークではプレートを明るく反転させ、貼っていただいた画像の見え方に寄せています

第3版で変えたこと（HUD 配色は採らない）

いただいた点どう描いたか
ネオンの色が切り替わらないデモの不具合でした。色を組み立てる変数をページの根元で計算していたため、切り替えた値が下へ届いていませんでした。グリーンの色相でガントの線だけ青のまま残っていたのも同じ原因です。切り替える要素の上で計算するように直しました（実装でも同じ罠があるので、章に書きます）
近未来感を色で出す「HUD」配色を足しました。① 土日祝の塗りを、上端が濃く下へ消えていく光の柱にし、ヘッダの日付の下に 2px の標示線を引く。② 色相を暦の赤（h=20）から、ディスプレイ寄りの青緑（h=228）とマゼンタ（h=350）に寄せる。③ ダークでは進行中のバーと「今」の線を発光させる。④ ヘッダの地にわずかに基調色を混ぜ、下端の線を基調色にする。⑤ 浮かせたペインの四隅に、ネオンの鉤括弧を付ける
浮かせたペインが赤みがかる裏の日曜・祝日の赤がぼかしで広がっていました。ぼかしと一緒に裏の彩度を 40% まで落とし、面そのものに基調色を混ぜて寒色のガラスにしました（ライト 5%、ダーク 14%）。裏で何かが流れている見え方は残しています
「今」の時刻が日付と重なる時刻の札をヘッダの最上段（年月の行）へ上げ、枠で囲みました。三角は日付の行の上端に残し、線はそこから下へ引きます
日付の無い親に期間を描く配下のうち最も早い開始から最も遅い終了までを、製図の寸法線（両端の縦線と、外を向いた矢印）で描きます。バーと形を変えて、自分の予定ではなく配下から導いた範囲だと分かるようにしました。文字は pb-88 配下 09/24–11/03 です。親を畳んでも出ます。依存線は寸法線に繋ぎません（自分の予定ではないため）
カーソルの縦横の点線と札帯の上でポインタを動かすと、縦の点線と、下端にその位置の日付（拡大すると時刻）を出します。横は第2版の対応線です。行の上ではチケットの ID・タイトル・期間の札がポインタの横に出ます

第2版で変えたこと

いただいた点どう描いたか設計文書との関係
色彩を増やすスプリント枠をネオンにした（下記）。土・日・祝に淡い色を敷いた。ダークでは進行中のバーを明るい段（step 10）で描き、塗りを濃くした8.1 の「有彩色は3つだけ」と 8.6 の「装飾に色を使わない」の例外になる。ガントの章に「ガントだけが使う色」として書き、8.6 の表にも1行足す
背景だけで土・日・祝を見分ける土＝青み、日＝赤み、祝＝赤み＋斜線。色が見分けにくい人でも、祝日は斜線で分かる（8.9）。日本の暦の慣習（土は青、日祝は赤）に揃えた
スプリントをネオンの枠に塗りをやめ、角丸の枠線だけにした。進行中は実線で発光させ、完了は薄く、計画中は破線にする。名前も進行中だけネオンの色で出す。色は切り替えて比べられる（シアン／ピンク）
ダークで見づらい完了のバー・依存線・斜線・行の罫の明るさを、ダークでだけ引き上げた。ガント専用のトークン（--g-*）に分け、ライトの見え方は変えていない8.5 のトークン表に足す
行と帯の対応付け① 帯の横の文字に ID を入れた（pb-220 10/08–10/20）。② ポインタを載せた行は、左端から帯まで点線を引き、ツリー側の右端にも印を出す。③ 画面の外にある帯は、端に札を出す（◂ pb-216 09/27）。札をクリックすると、その帯まで送る—
詳細を浮かせる不透明度 88% の面にぼかしを掛け、ガントの上に浮かせた。開いたときに選んだ帯がペインの下に隠れるなら、帯が見える位置まで時間軸を送る。右端の札もペインの左へ寄せる2.2.1 は「重ねない」と決めている。ガントでは例外にする。バックログで重ねないのは、覆われた列が読めないのに在る状態になるためだが、ガントの時間軸は送れば見えるので、この理由が当たらない

全案に共通の規則（第1版から引き継ぐもの）

  1. 時間軸ヘッダは2段。上の段は基準タイムゾーンで、大目盛りと小目盛りの2行を持つ。下の段は見る人のタイムゾーンで、基準と違うときだけ出す。見る人の0時には、本体まで点線を引く。
  2. 描く順番は、土日祝の塗り → 格子（行の強調・対応線を含む）→ スプリントの枠 → 「今」の線 → 依存線 → バー → 端の札（第4版で変更）。
  3. 日付の有無による出し分け。両方なしは行だけ、開始のみは [┄、終了のみは ┄]、両方あればバーで描く。両方なしでも配下に日付があれば、配下の期間を寸法線で描く（第3版）。
  4. 完了は行ごと沈める。期限超過は終わりの右に ⚠。
  5. 依存は色に頼らず、4つの手がかりで読み分ける。出入りする端、○ と ▶、FS 以外の札、ずらしの日数。blocks は一点鎖線で、受け側の端を止め（⊣）にする（第5版）。未確認の AI 提案は紫の破線にする。
  6. 行の高さは 28px。詳細ペインは既定 380px、320〜560px のあいだで変えられ、480px 未満ではメタ情報を1列にする。幅は pb.gantt_detail_pane_w に覚える。
