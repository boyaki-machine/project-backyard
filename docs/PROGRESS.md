## 環境メモ

**いま効いていて、かつ手順書に落とせない制約だけ。** 再現できる手順は `docs/Development.md`。

| 制約 | 効いてくる場面 |
|---|---|
| **秘密ファイルは Read からも Bash からも読めない**（`deploy/*/secrets/` は `.example` すら書けない） | 秘密を要する操作は `make` のターゲット経由。新しい環境の秘密は利用者が置く |
| **`git worktree` では `make test-db` が走らない**（`deploy/dev/secrets/` がチェックアウトされない） | `develop` でも落ちるかを見るとき。単体テストは走る |
| **`make test-db` は dev と同じ DB を使う** | 結合テストは走らせるたびに dev の `audit_log` を増やす |
| **`go test` の結果はキャッシュされる** | `openapi.yaml` だけを書き換えてもドリフト検出は再実行されない（`make test` は `-count=1`） |
| **このリポジトリに git のリモートが無い** | `git pull` は「no tracking information」で失敗する。ブランチは `git switch develop && git switch -c …` |
| **`make` はリポジトリ直下から実行する**（親を探しに行かない） | 他所から実行すると無音で失敗する |
| **検証の道具（`cdp.py` 等）はセッションをまたいで残らない** | スクラッチパッドは日付をまたぐと消える。毎回書き直す前提で組む |
| **追跡ファイルに実在のメールアドレス・氏名・ローカルパスを書かない** | ダミーは `@example.com`（既存54件、実在0件） |
| **`Runtime.evaluate` の式が `await` を含むなら、包む即時関数を `async` にする** | CDP で画面を測るとき |
| **一覧から消えたことを `document.body.innerText` で測らない** | 成功通知に名前が出るため。行の DOM を数える |
| **初期管理者 `tanaka@example.com` のパスワードは記録されていない** | 実サーバ検証は `make dev-seed` の4アカウントを使う（`make dev-info`） |
